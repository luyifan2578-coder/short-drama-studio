# Codex Skills

个人 Codex 技能仓库。

## 包含的技能

### short-drama-studio

用一套统一规则完成 AI 短剧的拆集拆镜、逐镜情绪设计、30 秒视频分镜提示词与电影感静帧故事板。

- **模式 A｜拆集拆镜**：时长预算（中文 4.5 字/秒、英文 2.7 词/秒，情绪对白 2.4—2.6）、边界规则、场景一致性、尾帧交接。
- **模式 B｜视频提示词**：Seedance 2.5 Pro、9:16 竖屏、单条不超过 30 秒；一般镜头 1—2 秒、最长 2.5 秒，持续揭示信息的运镜镜头按需延长；多机位不越轴。
- **模式 C｜静帧故事板**：21:9 或 9:16 的电影感单帧／三联／九镜，含连续性圣经、镜头账本与质量验收。

### short-drama-production

以剧本接收、资产交接、分镜、网页生成和本地交付串起已获授权的制作范围；调用本仓库的 `short-drama-studio` 生成正式分镜提示词。它自主比较并记录分镜方案，单独使用 `short-drama-studio` 时仍遵守其方案确认门禁。资产或视频生成只在相应范围获授权后进行。

### Studio 单集流程门禁与连续性控制（v6.4）

每一集在拆分镜与生成提示词之前，必须先走完四步，缺一不可：

1. **方案分析讨论**：先出方案，不出镜头清单，九项必含项齐全。
2. **弹出方案选项交互卡**：在对话界面给出可点选的方案选项，由用户点选或自行输入要求；只在正文里列编号选项不算过闸，当前模式发不出卡就先请用户切换模式。
3. **分镜拆解**：按确认后的方案定边界、定情绪、分配镜头与秒数。
4. **提示词生成**：逐段产出可整段复制的提示词并跑时长三重校验。

核心纪律：原文决定剧情事实，定稿资产图决定视觉外观，紧邻尾帧决定当前状态；对白与旁白不删减不改写；旁白与现场对白分轨、旁白期间全员闭口；每集走完四步门禁才动手；每条生成单元结尾有可交接的动态技术尾帧；服装和露肤范围按原文、资产及项目规则执行。

v3 新增连续状态账本：区分实际在场人物与本段主动人物，锁定绝对空间锚点、关系轴、活动区、禁区、道具生命周期和尾帧动作进程；使用 `REAL / DISPLAY / ARCHIVE / AUDIO / VO / POST` 区分现实现场、显示载体、档案影像、纯音频、画外音和后期文字，并为局部返修与交付验证设置明确状态。

v4 补充当前资产全正文审计、实体身份与显示内容分层、人物和道具状态变化的可见因果、相邻生成单元的实际尾帧验收，以及平台字符预算与交付证据分级。具体数值和图片后缀口径由项目规范决定。

v5 按不同剧本的实际写法识别同期状态，不限定括号符号；补充局部补镜的原片内部接点与自然状态变化的边界验收。Production 同步加入参考图职责区分、项目指定视频模式及局部补制交接规则，并在后续版本明确单人人物资产的默认五栏制作与验收规则。

v6 先按原文声音、动作与停顿核算集长，再拆生成单元；受限视角的线索与揭示遵守人物当下可知信息。两个技能均要求正式资产在提示词全文使用当前磁盘文件名主体（不含扩展名），重复引用仍写全名；原文台词和后期屏显文字不改写。Production 将单个分镜局部补制限为两次，并区分平台时间轴与本地接合交付版。

v6.2 按剧情信息选择固定机位或运镜；一般镜头以 1—2 秒为主，最长 2.5 秒，持续交付新信息的运镜镜头可按需延长并标记，不设运镜配额或固定镜头数。v6.3 明确提示词的原文与语义核对由执行助手完成；每份新稿或返修稿交付、提交前核对一次，返修重点检查改动处和相邻边界，无需用户逐镜或逐稿确认。Production 同步采用此内部质检口径，其自主方案选择规则保持不变。

v6.4 按剧情与项目要求选择实体屏内可读的原创界面或获准后期方案；不默认悬浮校字或不可读占位。服装与露肤范围不再套用性别化通用遮挡条款。证据和关键道具镜头用可见因果推进；Production 2026.10.29.2 明确人物身份返修以实际成片中的脸、发型、服装和剧情关系验收。

## 安装

把仓库里的 `skills/<技能名>` 目录复制到本机的技能目录：

| 系统 | 路径 |
|---|---|
| Windows | `C:\Users\<用户名>\.codex\skills\` |
| macOS / Linux | `~/.codex/skills/` |
| 设置过 `CODEX_HOME` | `$CODEX_HOME/skills/` |

要求：目标文件夹名与技能名一致，其根目录必须有 `SKILL.md`。复制完成后新开一个对话即可用 `$<技能名>` 调用。

也可以用 skill-installer 从本仓库安装：

```
从 luyifan2578-coder/short-drama-studio 仓库安装 skills/short-drama-studio
从 luyifan2578-coder/short-drama-studio 仓库安装 skills/short-drama-production
```
