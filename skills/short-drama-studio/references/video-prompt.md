# 30 秒视频提示词

默认后端：Seedance 2.5 Pro，原生 9:16 竖屏。

## 1. 交付形态

默认直接在对话里输出**可整段复制的纯文本**，一条生成单元一段，用户复制即用。不写文件，除非用户要求。文本内不使用 Markdown 表格与代码围栏，只用段落与固定字段标签。

## 2. 总体说明模板

    【场景】
    【时间天气】
    【人物与状态】形象与服装以随附资产图为准，本提示词不重复描述；只写状态（赤脚、包扎渗血、泪痕、衣摆凌乱等）
    【核心剧情】
    【情绪基调】这一段在演什么关系，并写明要排除的错误基调
    【实际在场／本段主动人物】分别列出；没有明确离场的人不得因本段无台词而消失
    【总镜头数】含技术尾帧
    【单镜时长】全部不超过 3 秒
    【空间初始位置】人物左右、朝向、距离，以及门窗、床、桌等固定物的位置关系
    【固定锚点／活动区／禁区】写可核对的绝对位置，避免“旁边”“略偏侧”
    【轴线与多机位】关系轴、机位所在半空间、左右归属、允许的机位类型
    【道具状态】持有者、当前位置、状态、首次出现点，以及属于现实层还是显示／档案层
    【相似道具互斥】按需写各实体的唯一身份、所在空间、可见镜头范围及不得互相替代的条件
    【时空与声源分层】按需标记 REAL／DISPLAY／ARCHIVE／AUDIO／VO／POST
    【运镜与转场】允许的运镜词，切点动机与声音桥
    【旁白与对白】语言与来源声明（如「全部按原文英文，不删不减，一字不改」）

## 3. 单镜头模板

    【镜头X｜0:00—0:XX】
    时长：
    景别：
    机位/摄影机：
    人物位置：
    动作：
    表演：按人物分别写情绪、视线目标与至少一个可观察微表演；背景人物也要有状态
    对白/VO：
    环境与物理：
    结束位置：

九项字段顺序固定，不得省略。

## 4. 技术尾帧镜头模板

    【镜头X｜0:28—0:30｜技术尾帧镜头】
    时长：1.5—2 秒
    景别：
    机位/摄影机：固定，稳定保持
    人物位置：
    动作：首帧继承上一镜的位置、身体高度、姿态、朝向、视线、手势、道具与动作进程，不新增剧情动作
    表演：保留呼吸、眨眼、视线停留、手指余动、衣料回落或动作自然收势；不得冻结
    对白/VO：无
    环境与物理：
    结束位置：与本镜开场位置一致，可直接作为下一段首帧

随后附【技术尾帧锁定信息】，字段见 [splitting.md](splitting.md) 第 6 节。

## 5. 声音写法

- 现场对白：写明「现场对白，仅 X 开口，仅朗读此字段」，后接原文本台词。
- 旁白与内心 VO：写明「画外、非叙事空间、单独录制，不从画面人物口中发出」，后接原文无引号文本。
- 每一镜都重复写明本镜人物是否闭口。VO 播放期间全员闭口、无口型。
- 旁白与对白不得在时间轴上重叠；先结束一段再进入下一段。
- 屏幕、录像、录音和后期文字分别标注 `DISPLAY/ARCHIVE/AUDIO/POST`；档案人物不得进入 `REAL` 现场，纯音频不得擅自扩写成闪回。
- 精确短信、法律文件、聊天记录和界面文字交给 `POST` 后期叠加；模型只生成可信载体、留字区域和观看反应。
- 手机阅读等人物戏保留真实载体、握持手、屏幕朝向和人物反应。`DISPLAY/POST` 文字跟随同一屏幕平面并受四边边框裁切；若用局部同步放大辅助观众阅读，限定其出现镜头、画幅区域与退场时点，不让人物观看或触碰这块辅助画面。

## 6. 自检清单

- 前 3 秒内建立场景、人物状态与钩子。
- 单镜不超过 3 秒；30 秒段落不少于 10 个镜头（含技术尾帧）。
- 每镜只有一个主要信息任务；按信息节点切镜，不做一镜到底。
- 对白与旁白全部取自原文，无删减、改写、合并。
- 人物反应符合「刺激 → 理解停顿 → 眼 → 头 → 肩 → 身体」时序。
- 多人反应错开 0.2—1 秒，每人都有明确情绪与视线。
- 空间连续：左右、距离、朝向、固定物关系前后一致；多机位不越轴。
- 人物在场连续：区分实际在场与本段主动人物；没有明确离场者不得凭空消失。
- 时空连续：REAL／DISPLAY／ARCHIVE／AUDIO／VO／POST 不串层，声源不互换。
- 道具连续：不提前出现、不凭空复制、不无动作换手；显示层出现不等于现实层已有。
- 人物、门和道具的新状态都有可见触发动作或明确跳切；门内外人物数量与相似道具身份互不冲突。
- 动作有物理因果与重量；道具受力、位移、结果成链。
- 手机、文件、证物袋等有明确手部抓持或桌面承托；显示内容被载体边框裁切，反射不生成人物分身。
- 情绪基调与原文一致，未被演成另一种类型。
- 有实际编号的技术尾帧镜头并计入总数，尾帧可直接作为下一段首帧。
- 全景和尾帧继承上一镜的身体高度、姿态、视线、道具和动作进程，不重新摆位、不冻结。
- 明确写出 Seedance 2.5 Pro 与 9:16 竖屏。
- 女性角色锁骨以下在全部镜头完整遮挡。
- 无中文或可读文字穿帮（本地化项目按目标语言处理画面内文字）。

## 7. 硬约束复述

每条提示词末尾固定复述本段的硬约束，例如：单镜不超过 3 秒；多机位不越轴；旁白与对白按原文；VO 期间全员闭口；女性角色锁骨以下完整遮挡；本段不得出现原文没有的人物、道具或事件。
