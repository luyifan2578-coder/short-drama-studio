# 30 秒视频提示词

默认后端：Seedance 2.5 Pro，原生 9:16 竖屏。

## 1. 交付形态

默认直接在对话里输出**可整段复制的纯文本**，一条生成单元一段，用户复制即用。不写文件，除非用户要求。文本内不使用 Markdown 表格与代码围栏，只用段落与固定字段标签。

## 2. 总体说明模板

    【场景】
    【正式参考资产】每行一个当前正式资产的完整文件名主体（默认不含路径或扩展名）；逐镜再次提及时仍写完整主体。尚无正式资产时写“无正式资产”，并在方案旁列缺口
    【时间天气】
    【人物与状态】形象与服装以随附资产图为准，本提示词不重复描述；只写状态（赤脚、包扎渗血、泪痕、衣摆凌乱等）
    【核心剧情】
    【情绪基调】这一段在演什么关系，并写明要排除的错误基调
    【实际在场／本段主动人物】分别列出；没有明确离场的人不得因本段无台词而消失
    【总镜头数】含技术尾帧
    【单镜时长】一般镜头以 1—2 秒为主，最长 2.5 秒；有剧情信息推进的运镜镜头按需定长
    【空间初始位置】人物左右、朝向、距离，以及门窗、床、桌等固定物的位置关系
    【固定锚点／活动区／禁区】写可核对的绝对位置，避免“旁边”“略偏侧”
    【轴线与多机位】关系轴、机位所在半空间、左右归属、允许的机位类型
    【道具状态】持有者、当前位置、状态、首次出现点，以及属于现实层还是显示／档案层
    【相似道具互斥】按需写各实体的唯一身份、所在空间、可见镜头范围及不得互相替代的条件
    【时空与声源分层】按需标记 REAL／DISPLAY／ARCHIVE／AUDIO／VO／POST
    【运镜与转场】本段哪些信息适合固定机位，哪些需要运镜；写明运镜的剧情目的与切点动机，不设数量配额
    【旁白与对白】语言与来源声明（如「全部按原文英文，不删不减，一字不改」）

## 3. 单镜头模板

    【镜头X｜0:00—0:XX】
    时长：
    景别：
    机位/摄影机：固定机位写清构图；运镜写清起始构图、触发动作、移动方向与速度、结束构图及新增信息
    人物位置：
    动作：
    表演：按人物分别写情绪、视线目标与至少一个可观察微表演；背景人物也要有状态
    对白/VO：
    环境与物理：
    结束位置：

九项字段顺序固定，不得省略。

## 4. 运镜选择与时长例外

- 逐镜先确定观众在镜头开始与结束分别需要知道什么。固定机位或直接切镜已能清楚交代时，使用固定机位；人物行动需要被连续跟随、道具或遮挡需逐步揭示关键内容、人物关系需在同一动作中改变时，才选择有动机的运镜。整段不设运镜数量或类型配额。
- 一般镜头以 1—2 秒为主，最长 2.5 秒。运镜镜头只有在移动途中持续交付新的剧情信息或必要的空间关系时才可按实际需要延长；不能用缓慢移动填补等待、静物展示或重复反应。技术尾帧仍按交接需要稳定收束。
- 超过 2.5 秒的运镜在标题写「【镜头X｜起止秒点｜运镜镜头】」。九项字段不变；在「机位/摄影机」写起始构图、触发点、物理可行的路径与速度、结束构图；在「动作」「结束位置」写移动中逐步出现的信息和停下时观众获得的结论。镜头时长以这些信息节点所需的正常动作时间为准。
- 执行助手在提示词提交前核对：移走这段运镜，改为固定机位或直接切镜，是否会丢失关键发现、行动关系或情绪转折？若不会，改用固定机位或切镜。运镜不得让演员放慢动作、跨轴、穿越实体或改变人物和道具的连续状态。脚本只核标题与时长；助手需核对文本中的信息增量和运动必要性，成片后再看实际效果，无需为此逐镜请用户确认。

## 5. 技术尾帧镜头模板

    【镜头X｜0:28—0:30｜技术尾帧镜头】
    时长：1.5—2 秒
    景别：
    机位/摄影机：固定，稳定保持
    人物位置：
    动作：首帧继承上一镜的位置、身体高度、姿态、朝向、视线、手势、道具与动作进程，不新增剧情动作
    表演：保留呼吸、眨眼、视线停留、手指余动、衣料回落或动作自然收势；不得冻结
    对白/VO：无
    环境与物理：
    结束位置：与本镜开场位置一致，可直接作为下一段首帧

随后附【技术尾帧锁定信息】，字段见 [splitting.md](splitting.md) 第 6 节。

## 6. 声音写法

- 现场对白：写明「现场对白，仅 X 开口，仅朗读此字段」，后接原文本台词。
- 旁白与内心 VO：写明「画外、非叙事空间、单独录制，不从画面人物口中发出」，后接原文无引号文本。
- 每一镜都重复写明本镜人物是否闭口。VO 播放期间全员闭口、无口型。
- 旁白与对白不得在时间轴上重叠；先结束一段再进入下一段。
- 屏幕、录像、录音和后期文字分别标注 `DISPLAY/ARCHIVE/AUDIO/POST`；档案人物不得进入 `REAL` 现场，纯音频不得擅自扩写成闪回。
- 需要观众读清的短信、聊天、文件和界面文字，先核对原文内容及项目指定的呈现方式。要求模型生成屏内文字时，用原创、无平台标识的界面让原文自然出现在实体载体内，并在成片逐字检查；不能因模型文字不稳定就擅改为不可读占位。只有项目选用后期方案时才写 `POST`，文字仍须贴附同一载体的屏幕或纸面，不使用悬浮校字层。
- 手机阅读等人物戏保留真实载体、握持手、屏幕朝向和人物反应。屏内 `DISPLAY` 或获准的 `POST` 文字跟随同一屏幕平面并受四边边框裁切；若用局部同步放大辅助观众阅读，限定其出现镜头、画幅区域与退场时点，不让人物观看或触碰这块辅助画面。平台不能可靠生成要求的文字且项目不接受后期时，记录具体限制，不自行改变剧情信息。

## 7. 自检清单

- 前 3 秒内建立场景、人物状态与钩子。
- 一般镜头以 1—2 秒为主、最长 2.5 秒；超过 2.5 秒的运镜镜头已标记，并由执行助手核实持续新增信息。镜数由有效信息节点决定，技术尾帧计入总数，不为凑数切镜。
- 固定机位足够时没有多余运镜；需要运镜时已写明目的、触发、路径和结束信息，运动与人物正常速度同步。
- 每镜只有一个主要信息任务；按信息节点切镜，不做一镜到底。
- 对白与旁白全部取自原文，无删减、改写、合并。
- 当前剧本中承载同期状态的括注、动作说明或其他格式，已逐项落到相应剧情时刻的画面／声音；内部先后顺序及跨单元未结束状态得到继承。
- 人物反应符合「刺激 → 理解停顿 → 眼 → 头 → 肩 → 身体」时序。
- 多人反应错开 0.2—1 秒，每人都有明确情绪与视线。
- 空间连续：左右、距离、朝向、固定物关系前后一致；多机位不越轴。
- 人物在场连续：区分实际在场与本段主动人物；没有明确离场者不得凭空消失。
- 时空连续：REAL／DISPLAY／ARCHIVE／AUDIO／VO／POST 不串层，声源不互换。
- 道具连续：不提前出现、不凭空复制、不无动作换手；显示层出现不等于现实层已有。
- 证据和关键道具是否通过可见动作、状态变化与发现过程推进；静物特写是否提供了新的剧情信息，而非连续重复展示。
- 需要可读屏内文字时，是否保留原文、实体屏幕边界和原创无标识界面；是否避免未经要求的悬浮校字、不可读占位。
- 人物、门和道具的新状态都有可见触发动作或明确跳切；门内外人物数量与相似道具身份互不冲突。
- 动作有物理因果与重量；道具受力、位移、结果成链。
- 手机、文件、证物袋等有明确手部抓持或桌面承托；显示内容被载体边框裁切，反射不生成人物分身。
- 情绪基调与原文一致，未被演成另一种类型。
- 受限视角段落的线索有主视角人物可感知的来源，判断和身体反应在发现之后；未提前展示原文尚未揭示的信息。
- 正文全部已有正式资产引用均为磁盘文件名主体（不含扩展名），重复出现仍写全名；原文对白／旁白与后期屏显文字保持原文。
- 有实际编号的技术尾帧镜头并计入总数，尾帧可直接作为下一段首帧。
- 全景和尾帧继承上一镜的身体高度、姿态、视线、道具和动作进程，不重新摆位、不冻结。
- 明确写出 Seedance 2.5 Pro 与 9:16 竖屏。
- 服装、露肤范围及必要遮挡是否符合原文、正式资产与当前项目规则，没有额外加入通用的性别化覆盖要求。
- 无中文或可读文字穿帮（本地化项目按目标语言处理画面内文字）。

## 7. 硬约束复述

每条提示词末尾固定复述本段适用的硬约束，例如：一般镜头最长 2.5 秒、运镜例外须持续揭示信息；多机位不越轴；旁白与对白按原文；VO 期间全员闭口；本段不得出现原文没有的人物、道具或事件。服装与遮挡只复述原文、正式资产或项目实际要求，不自动加入通用的性别化遮挡条款。
