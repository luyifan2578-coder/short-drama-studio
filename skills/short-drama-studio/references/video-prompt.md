# 30 秒视频提示词

默认后端：Seedance 2.5 Pro，原生 9:16 竖屏。

## 1. 交付形态

默认直接在对话里输出**可整段复制的纯文本**，一条生成单元一段，用户复制即用。不写文件，除非用户要求。文本内不使用 Markdown 表格与代码围栏，只用段落与固定字段标签。

## 2. 总体说明模板

    【场景】
    【时间天气】
    【人物与状态】形象与服装以随附资产图为准，本提示词不重复描述；只写状态（赤脚、包扎渗血、泪痕、衣摆凌乱等）
    【核心剧情】
    【情绪基调】这一段在演什么关系，并写明要排除的错误基调
    【总镜头数】含技术尾帧
    【单镜时长】全部不超过 3 秒
    【空间初始位置】人物左右、朝向、距离，以及门窗、床、桌等固定物的位置关系
    【轴线与多机位】关系轴、机位所在半空间、左右归属、允许的机位类型
    【运镜与转场】允许的运镜词，切点动机与声音桥
    【旁白与对白】语言与来源声明（如「全部按原文英文，不删不减，一字不改」）

## 3. 单镜头模板

    【镜头X｜0:00—0:XX】
    时长：
    景别：
    机位/摄影机：
    人物位置：
    动作：
    表演：按人物分别写情绪、视线目标与至少一个可观察微表演；背景人物也要有状态
    对白/VO：
    环境与物理：
    结束位置：

九项字段顺序固定，不得省略。

## 4. 技术尾帧镜头模板

    【镜头X｜0:28—0:30｜技术尾帧镜头】
    时长：1.5—2 秒
    景别：
    机位/摄影机：固定，稳定保持
    人物位置：
    动作：保持上一镜形成的最终状态，不新增大动作
    表演：仅保留呼吸、衣料或环境造成的自然微动
    对白/VO：无
    环境与物理：
    结束位置：与本镜开场位置一致，可直接作为下一段首帧

随后附【技术尾帧锁定信息】，字段见 [splitting.md](splitting.md) 第 6 节。

## 5. 声音写法

- 现场对白：写明「现场对白，仅 X 开口，仅朗读此字段」，后接原文本台词。
- 旁白与内心 VO：写明「画外、非叙事空间、单独录制，不从画面人物口中发出」，后接原文无引号文本。
- 每一镜都重复写明本镜人物是否闭口。VO 播放期间全员闭口、无口型。
- 旁白与对白不得在时间轴上重叠；先结束一段再进入下一段。

## 6. 自检清单

- 前 3 秒内建立场景、人物状态与钩子。
- 单镜不超过 3 秒；30 秒段落不少于 10 个镜头（含技术尾帧）。
- 每镜只有一个主要信息任务；按信息节点切镜，不做一镜到底。
- 对白与旁白全部取自原文，无删减、改写、合并。
- 人物反应符合「刺激 → 理解停顿 → 眼 → 头 → 肩 → 身体」时序。
- 多人反应错开 0.2—1 秒，每人都有明确情绪与视线。
- 空间连续：左右、距离、朝向、固定物关系前后一致；多机位不越轴。
- 动作有物理因果与重量；道具受力、位移、结果成链。
- 情绪基调与原文一致，未被演成另一种类型。
- 有实际编号的技术尾帧镜头并计入总数，尾帧可直接作为下一段首帧。
- 明确写出 Seedance 2.5 Pro 与 9:16 竖屏。
- 女性角色锁骨以下在全部镜头完整遮挡。
- 无中文或可读文字穿帮（本地化项目按目标语言处理画面内文字）。

## 7. 硬约束复述

每条提示词末尾固定复述本段的硬约束，例如：单镜不超过 3 秒；多机位不越轴；旁白与对白按原文；VO 期间全员闭口；女性角色锁骨以下完整遮挡；本段不得出现原文没有的人物、道具或事件。
