# 拆集与拆镜

## 1. 时长预算

先把原文的朗读文本换算成秒，再决定分成几条生成单元。

| 语言 | 语速基准 | 说明 |
|---|---|---|
| 中文 | 4.5 字/秒 | 短剧对白偏快，情绪戏可降到 4.0 |
| 英文 | 2.7 词/秒（情绪对白 2.4—2.6） | 同一句内容英文普遍比中文长约 1.5 倍 |

每条声音另加 0.3—0.7 秒句间停顿；每条生成单元固定预留 1.5—2 秒技术尾帧。

**硬约束**：每集 60—90 秒；单条生成单元不超过 30 秒；30 秒内不少于 10 个镜头且单镜不超过 3 秒。

**先按上述语速算出每集的朗读总量，再决定分 2 条还是 3 条**，不要先分条再往里塞内容。

## 2. 装不下时的处理顺序

对白与旁白不得删减，因此按以下顺序处理：

1. 按场景转换点把这一集拆成更多生成单元（60 秒 → 90 秒，即 2 条 → 3 条）。
2. 仍装不下时，收紧句间停顿、把语速提到英文 3.0—3.2 词/秒。
3. 仍装不下才是超长集，回到用户确认，不要自行删除原文。

把「舞台指示型」的叙述句（例如「他把我拉进怀里」「男人的笑意不减」）改写成可见表演而非配音，是**允许的转译**，不是删减，前提是该句描述的动作必须真的被拍到。第一人称的内心叙述与全部对白必须保留声音。

## 3. 边界规则

1. 优先落在**场景转换点**：出门、进门、转场、时间跳点。
2. 其次落在**事件完成、悬念未解**处，让每条结尾带钩子。
3. **不得**切在同一句对白或同一个连续动作中间。
4. 集与集之间尽量同场景直接续接；跨日或跨场的硬切必须在提示词里写明「硬切」并完整重述新空间。
5. 边界落在话未说完处时，尾帧必须锁定「开口未闭、话未说完」的状态。
6. 边界一旦锁定，列出全部边界行号，后续不得私自移动。

## 4. 场景一致性优先级

- 一条生成单元尽量只占**一个场景、一种光态、一套造型**。
- 必须跨场景时，用一镜连续跟拍承载（例如「摔门 → 转身走回卧室」），而不是把两个场景硬拼进同一镜。
- 场景转换无法避免时，把它放在这条生成单元的最前或最后，不要放在中段。
- 同一场连续事件的几条单元，共用同一光源、同一桌面陈设、同一道具状态，建议一次拍完。

## 5. 交接表

每条边界都用一张表锁住，模板：

| 边界 | 衔接类型 | 尾帧必须记录的状态 |
|---|---|---|
| 第X条 → 第Y条 | 同场景续接／跨日硬切／同一句话中间的续接 | 人物位置、姿态、朝向、距离、道具与光源状态 |

## 6. 技术尾帧锁定信息

每条生成单元末尾必须写出这一块，字段固定：

- 人物：谁在画面左、谁在画面右，姿态与相互关系。
- 姿态：坐／卧／站／跪，朝向，彼此距离。
- 服装与遮挡：造型状态；女性角色锁骨以下的覆盖方式。
- 关键道具与固定物：门窗、床、桌、灯、武器等锚点的相对位置。
- 光源：光源位置与性质，是否有变化。
- 声音：底噪、持续声源。
- 下一段起点：下一单元首镜如何从这一状态起步。

## 7. 情绪基调先行

拆完边界后，先为每条生成单元写一句**情绪基调**，再分配镜头。基调写错，镜头全废。

判断方法：读这一段的原文，问「这场戏在演什么关系」，而不是「发生了什么」。例如：

- 隔着墙听隔壁、尴尬却忍不住听、发现对方在看戏 → 基调是**暧昧与被逗乐**，不是紧张。
- 同一场戏的后半段才出现「充满攻击性」的描写 → 情绪转向发生在后半段，不能提前渗到前段。

每条生成单元的总体说明里都要显式写出情绪基调，并在硬约束里排除会污染基调的表演（如「不得出现恐惧、僵住、威胁类表情」）。

## 8. 输出格式

模式 A 的输出是一张分集分镜表，逐行给出：集 / 生成单元编号 / 原文行号 / 时长 / 场景 / 内容边界 / 边界依据；后附交接表与全部锁定边界行号。
