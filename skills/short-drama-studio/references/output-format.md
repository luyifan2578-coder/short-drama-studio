# 输出格式、锁定模板与自查清单

## 1. 正式生成前的分析顺序

收到原文章节后，先分析并明确，再分配镜头和秒数：

1. 场景在哪里。
2. 有哪些人物。
3. 人物使用什么服装和状态。
4. 上一场如何进入本场。
5. 核心动作是什么。
6. 核心情绪如何变化。
7. 哪些句子必须获得对应画面。
8. 哪些信息节点需要切镜。
9. 最终人物位置是什么。
10. 下一段从什么状态和位置接续。
11. 实际在场人物与本段主动人物分别是谁。
12. 是否存在 REAL／DISPLAY／ARCHIVE／AUDIO／VO／POST 分层。

## 2. 标准输出格式

完整 30 秒视频先输出总体说明，再说明总镜头数和空间初始位置，然后按时间轴输出。总镜头数必须包含最后的技术尾帧镜头。

总体说明模板：

```text
【30秒分镜总体说明】
场景：
时间/天气：
人物与服装状态：
实际在场人物 / 本段主动人物：
核心剧情：
总镜头数：
空间初始位置：
固定锚点 / 活动区 / 禁区：
道具状态与层级：
时空与声源分层：
```

单镜头模板：

```text
【镜头X｜0:00—0:XX】
时长：
景别：
机位/摄影机：
人物位置：
动作：
表演：
对白/VO：
环境与物理：
结束位置：
```

`表演`字段按人物分别书写，为每位画面中的人物明确当前情绪、视线目标和可观察微表演；背景人物也不得无状态站立。

技术尾帧镜头模板：

```text
【镜头X｜0:28—0:30｜技术尾帧镜头】
时长：约 2 秒
景别：
机位/摄影机：固定，稳定保持
人物位置：
动作：首帧继承上一镜的位置、身体高度、姿态、朝向、视线、手势、道具与动作进程，不新增剧情动作
表演：仅保留呼吸、眨眼、视线停留、手指余动、衣料回落或动作自然收势，不得冻结
对白/VO：无
环境与物理：
结束位置：与本镜开场位置一致，可直接作为下一段首帧
```

技术尾帧锁定信息（仅注释，不替代尾帧镜头）：

```text
【技术尾帧锁定信息】
```

该模块需完整写明人物、关键道具与固定场景物的最终位置、朝向、距离和姿态。

## 3. 角色与资产锁定模板

每个主要角色建立一条锁定记录，后续所有分镜不得擅自更改。

```text
【角色锁定】角色名：
性格底线：不能演成……（例如：强者不能演成卑微、软弱）
固定外形特征：脸型、发色、瞳色、体型、标志特征
特殊身体特征及物理表现：如尾巴、翅膀、鳞片、獠牙的重量感与运动方式
情绪表现方式：通过哪些细节表达（眼神、呼吸、下颌、手指、重心）
动作与战斗风格：快速准确或沉重有力等
禁忌演出：禁止夸张瞪眼、尖叫、无意义翻滚等
```

服装与状态模板：

```text
【服装状态】名称：
固定结构：领口、袖型、材质、颜色、配饰
可变状态：完整 / 湿水 / 破损 / 沾血 / 换装，变化必须写清渐变过程
遮挡要求：女性角色锁骨以下必须始终覆盖
```

场景资产模板：

```text
【场景资产】名称与编号：
空间锚点：门、窗、床、桌、王座、台阶、楼梯的相对位置
固定材质与光线：墙体、地面、光源方向
可变状态：昼夜、天气、破坏、撤离等
```

道具模板：

```text
【道具锁定】名称：
固定视觉特征：材质、颜色、大小、磨损
关键使用动作：如何被拿起、使用、受力、落地
```

特殊场景合规模板（沐浴、换装、亲密、水中场景）：

- 明确进入过程，禁止直接跳切为已在水中或已换装。
- 优先后背、侧后方或过肩构图，不拍女性前胸；所有机位继续执行锁骨以下完整遮挡。
- 遮挡以服装或道具为主，水面、蒸汽、前景只能作为附加遮挡，不能作为唯一遮挡。
- 服装不透明、不贴身透出轮廓、不滑落敞开；湿水或受力只产生真实褶皱。
- 禁止使用低机位、俯拍水下视角、透明水体或身体贴水构图规避遮挡要求。
- 亲密动作按连续因果衔接，不跳过动作起点、接触过程或身体受力结果。

## 4. 分镜输出自查清单

每段分镜完成后逐项检查：

- 前 3 秒是否建立场景、人物状态和钩子。
- 每个镜头是否只有一个主要信息任务。
- 是否按信息节点主动切镜，而不是一镜到底或机械拆秒。
- 30 秒段落是否至少有 10 个镜头（含技术尾帧）；内容单一的长镜头是否已拆为承载新增叙事或情绪信息的有效短镜头。
- 人物反应是否符合刺激、理解、眼睛、头、身体的时序。
- 多人反应是否错开，是否所有人物都有明确情绪状态。
- 空间是否连续：左右、距离、朝向、固定物关系是否一致。
- 动作是否有物理因果和重量。
- 对白与旁白是否分轨，VO 期间是否全员闭口、无口型。
- 旁白与内心 VO 是否无引号写入。
- 资产、服装、场景、道具描述是否与锁定模板一致。
- 是否明确 9:16 竖屏和 Seedance 2.5 Pro 适配。
- 女性角色锁骨以下是否在所有镜头完整遮挡。
- 最后是否有实际生成的技术尾帧镜头，并计入总镜头数。
- 尾帧能否直接作为下一段首帧输入。

## 5. 最终执行口诀

- 不是一镜到底，是信息到了就切。
- 不是角色突然反应，是刺激、理解、眼睛、头、肩膀、身体。
- 不是只写动作发生，而是写清动作为什么发生、如何发生、造成什么结果。
- 不是这一镜单独好看，而是上一镜能接、下一镜也能接。
- 不是 AI 角色演戏，而是真人演员在真实空间中完成真实动作。
- 所有重要段落最后必须用一个实际编号短镜头生成可继续下一段的明确技术尾帧。
- 所有生成提示词默认明确写入 9:16 竖屏条件，并按竖屏逻辑完成构图与调度。
- 旁白和对白必须分轨表达：旁白进行时全画面人物闭口无口型，只有现场对白段落才允许指定角色开口。
- 所有镜头中的女性角色锁骨以下必须完整遮挡，不得暴露上半身裸露身体。
