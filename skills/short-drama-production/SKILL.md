# 短剧全流程制作｜分镜工作室版

本技能将**项目接收、资产交接、网页执行、结果核验和本地交付**串成一条流程；分镜创作使用同机安装的 [`short-drama-studio`](../short-drama-studio/SKILL.md)。本技能对其方案门禁有一项明确覆盖：分析方案后自主择优并继续执行，不要求逐集弹交互卡或等待例行确认。旧版 `jiuzhou-drama-workflow` 的内置 30S 正文、七字段母版和相应检查脚本不适用于本技能的新稿。单独使用 `short-drama-studio` 时，其原有方案门禁不变。

先按本次请求确定终点。安装、修订或讨论技能，只处理技能；盘点、核对或修改资产清单不授权生图；只做分镜不授权网页提交。完整制作仅在用户对当前项目、范围和生成阶段已有明确授权时推进。项目 `AGENTS.md`、用户已确定的剧本及资产规则优先于通用技能默认值；不把别的项目的造型、模型、费用、授权或暂停状态带进来。

## 阶段选择

| 用户的本次范围 | 执行与停止点 |
|---|---|
| 建档或自动拆集 | 核验来源、保存原稿；按项目要求拆集并逐字回拼，交付分集稿后停止 |
| 全剧资产盘点 | 交付人物、场景、道具三类需求；明确出镜与镜头备选，停止于清单 |
| 已明确授权制作资产 | 核对现有图片并只在授权范围补图；逐张验收，集中交接用户改图 |
| 只做分镜或局部返修 | 按 `short-drama-studio` 完成指定范围，停在经检查的文本和用户指定文件 |
| 完整视频制作或明确断点接续 | 完成获准范围的分镜、网页任务、本地原片和顺序成片；按实际状态交付 |
| 暂停或只查状态 | 不发起新资产或视频任务；核对已受理与未知状态并保存断点 |

## 1. 剧本、项目和资产

读 [来源、拆集与资产交接](references/source-and-assets.md)。读取当前剧本和项目规则；保留来源文件、语言版本、路径及 SHA256。全文分析人物关系、时间线、揭示顺序和空间。独立项目不覆盖同名异稿。自动英文拆集仍以原文字符流不变、每集至少 400 英文词和最多 35 集为默认合同；已有锁定集界或用户指定规则优先。

资产需求按人物、场景、道具三类列清；人物时期与状态放在同一身份下。现有图片须逐张看实际内容、尺寸、名称和指纹；把身份参考、体型或结构参考、正式资产各自的约束范围分开验收，不把参考图误当成成品图。获准制作单人人物资产时，按 [人物资产制作与验收规则](references/source-and-assets.md#人物资产制作与验收) 确定五栏版式、同一造型、空手及独立道具分离；项目另有明确版式时按项目规则执行。只有用户明确要求制作相关资产才生成、提交或下载；图片制作和人工改图交接依项目要求执行。资产清单中的镜头备选不写成剧本事实，也不提前制作。全剧资产交接后若需用户修改，保存断点并等其继续；恢复时复查变更图和依赖，不重复生成已确认素材。

## 2. 分镜创作与直接提交

读 [分镜工作室接入](references/storyboard-integration.md)，再按本次任务读取 `short-drama-studio` 的 `SKILL.md` 和其相关引用页。创作分镜、情绪、表演、机位、技术尾帧、层级标记及文本证据都采用工作室的**当前**规则。每集先完成其方案分析，比较可行边界、时长、场景、情绪和连续性安排，自主选定最符合原文与项目约束的方案，简要记录依据后直接拆镜、出提示词。方案选择不设交互卡或例行确认；只有权威原文冲突、关键输入缺失或涉及尚未授权的生成与费用时，才就具体阻塞点询问。记录实际规则版本与所用文件指纹，不把历史版本号当作当前规则。

已授权的批次可先完成各集方案定稿与正式分镜，再进入视频阶段；同场连续单元的后段书面首态在前段实际成片前仍属暂定。提交后段前，按工作室规则查看前段实际尾态，必要时仅修订受影响的后段首态并重查相邻边界。

`short-drama-studio` 生成并核对的正式分镜提示词就是网页提交正文，不另制或另存平台稿。原文对白及已确认 VO／OS 的画面、声音与时间线均留在同一份提示词中；需要后期配音时可另存配画表供后期使用，不为提交平台删改分镜内容或声源指令。提交前核对平台限制；确需调整时只修订这份正式提示词并重查受影响镜头，无法兼容时报告冲突，不暗中生成第二版。网页素材选择器的真实引用节点须逐项绑定并核验；字面 `@` 不等于真实绑定。

完整制作的正式文件按项目约定保存分镜正文及旁白覆盖表；需要 DOCX 时渲染检查。只做工作室文本任务时遵从其默认对话交付或用户指定路径。项目要求的视觉版式、文件名、语言、女性服装等覆盖技能通用示例。

## 3. 网页生成与结果交付

读 [网页执行与本地交付](references/platform-and-delivery.md)。进入目标平台前核实项目、集号、当前正文与图片版本；模型、画幅、单次时长、素材容量和价格以**当前页面**为准，不能沿用旧项目或默认值。先读取项目指定的视频模式及该模式的真实素材引用方式；没有指定时按当前平台能力和任务要求选择，并记录依据。每个生成单元在选定模式下实际绑定所需人物／场景／道具，以及连续接续所需的真实尾帧，读回正文和参数后记录一次尝试及价格，只提交一次；受理不明先查历史，不重复点击。

对连续场，前段成片实际尾态与后段首态构成提交依赖；新场景、明确跳时等可自包含的单元可按当前授权独立推进。局部质量偏差先定位原片中可保留的画面及剪接点；有该次补制授权后，才为异常镜头及必要衔接镜头提交一次短段任务，按原片保留段的实际尾帧接续并核对拼接处。用户未授权补制时，失败和质量偏差只记录与报告，不自动收费重做。暂停后停止新提交，已受理任务继续核对状态。

区分提示词完成、平台受理、视频完成、实际审片、边界验收、下载、本地合片和用户确认。按当前审查范围查看真实视频与音轨；未审查标记 `not_reviewed`。导出逐集原片，核对文件、时长、尺寸、音轨和指纹，再按序合片；缺段标为不完整。完整视频任务默认终点是获准范围的本地原片及顺序成片，不自行加字幕、后期 VO、音乐、剪映草稿或发布。

## 4. 状态与恢复

读 [状态和证据](references/state-and-resume.md)。来源、资产、正式分镜提示词、网页引用、提交尝试、返回结果和本地文件分别记录版本与证据。计划、脚本检查或平台受理不代表成片合格。正文、图片或规则改变后，只使受影响的未提交核验失效；已受理和已完成结果保留历史。恢复时先读取当前状态与真实文件、网页任务，再决定下一步，避免重复上传、扣费或建项目。
