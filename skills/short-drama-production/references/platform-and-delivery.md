# 网页执行、结果与本地交付

## 提交前

1. 进入用户指定的真实平台项目，核对登录、项目、集号、页面分镜序号及既有任务。工具或页面变化时读取当前状态与工具文档，不复用旧坐标、元素编号、模型价格或素材容量。
2. 从 `short-drama-studio` 生成的正式分镜提示词列出本单元全部必需人物、场景和道具及其时期，以及连续场所需的实际尾帧。将选定的实际尾帧归档为接续资产，记录源任务、取帧时间点、文件路径及指纹；提示词全文每次提及正式人物、场景、道具或尾帧资产，均写当前磁盘完整文件名主体（不包含扩展名），无称谓、简称、旧名或泛称代替。先核对项目规定的视频模式；没有规定时核对平台当前可用模式并选择能满足本次引用与接续要求的一种。`D:\短剧\八个哥哥` 的剧梦分镜视频生成及返修固定使用“全能参考”，不得转用“首尾帧”“视频编辑”“图片生成”等模式。查看实际图片，必要时按用户授权上传；在选定模式的真实选择器中形成本段全部必需正式资产及实际尾帧的引用节点。提交前逐项核对类别、文件内容、节点位置和页面读回，不能把字面 `@` 或素材栏存在当成功；真实节点自动显示的扩展名按平台实际界面核对。项目锁定模式时不得为方便返修擅自切换。
3. 剧梦连续分镜先从前一分镜实际成片末尾选取能呈现**结束时空间结构与人物站位**的一帧作尾帧，不机械截取文件最后一帧；确认取帧之后没有改变该状态的动作。若末尾为切黑、遮挡或无法定位的特写，选更早但仍代表最终状态的有效帧；没有有效帧则不通过尾帧验收。记录该帧人物空间站位、场景关系、道具与光态，再核对下一分镜首态；相邻集数的集尾与集首属于同一连续场景时同样适用。不得凭空换位或重置场景；朝向、手势、表情和机位可随可见动作与剧情自然变化，不要求两帧画面完全相同，也不以这些自然变化单独判失败。冲突时先修订下一正式提示词，无法自然衔接则暂停提交。验收通过后，用剧梦引用功能将**所选取的这一帧**绑定为下一分镜的开头承接状态资产；本项目在“全能参考”内同时绑定本段必需的正式人物、场景、道具资产。在下一正式提示词的承接位置写明“承接上一分镜尾帧”，跨集时注明“上一集末分镜”，并在该处插入真实引用节点。提交前核对所有节点来源任务、取帧时间点、版本和页面读回，不以书面尾帧或字面说明代替绑定；生成后核对相邻镜头的人物空间站位与场景关系。
4. 按本项目解析模型、分辨率、画幅、时长模式；页面实际值、平台允许的最大时长和本次价格都要读回。页面正文除真实引用节点的展开形式外，须与正式提示词一致。发现超长、缺图、声音安排冲突或正文差异时，回到同一份正式提示词修订并重核；无法兼容时暂停提交并报告。
5. 记录正文与素材指纹、页面身份、参数、预算、尝试编号及实际价格，再点击生成一次。页面响应不明先查历史、队列或任务卡；不能为试探受理而再点一次。

## 受理、失败与暂停

- 受理后读回该次任务及真实引用，把提交后漏引用、在途、已生成和失败分别记。连续场下一单元需前段实际尾态时，等待该依赖；无依赖单元仍按本次授权与平台能力推进。
- 局部画面异常时先保留合格区间，记录原片版本、可剪接画面及时间点。获该次补制授权后，仅将异常镜头与必要的邻近镜头写成一段短提示词，在原分镜位置以项目锁定的视频模式提交一次短时长局部新任务，避免重复生成多数合格镜头；若当前平台无法在原位置以该模式提交此类任务，先报告能力限制，不换模式或改用整段重生。首态引用紧邻保留段结束状态的**有效定位帧**：异常在中段用前方保留段末尾能说明人物站位的一帧，在开头且无本段保留前缀时用上一个连续分镜的有效尾帧；不能引用异常画面、书面预想尾帧或无关任务尾帧。补段首镜逐项核对角色空间站位、服装、道具和光态。补段完成后与原片合格区间拼接，核对原问题、前后拼接点和新尾态；未通过先报告，不自动再次扣费。
- 每个原分镜最多两次局部补制，首次补制和再补制合计；先查历史次数再提交。已受理任务即使模型超时、参考图比例错误或产物不合格也计入，未受理的表单／审核拦截不计。两次后仍不合格就停止该分镜局部补制，保留原片合格部分，在最终问题清单写明位置、现象、两次尝试结果和剩余影响，由用户判断；不能通过另建版本或重投同一分镜绕开计数。只有用户明确更改上限时才覆盖。
- 剧本中的“脸色发白／turned pale”只用细微可信的生理变化及即时表演呈现：保留正式资产的肤色、妆容、肤质和场景光照，以笑容收住、呼吸停顿、眼神及唇部反应表现冲击，面部血色变化须轻微且与颈部、肩部一致。禁止整脸惨白或灰白面具、闪白、涂层、换脸、局部曝光突变、发光眼睛等效果。成片逐镜核对脸与颈部色调过渡及相邻镜头一致性；异常按局部规则记录镜号、时间点及受光状态，不把少量抽帧或提示词禁令当作已修复。
- 审核拦截须先确认原任务未受理或已终结。不得改写原文规避审核；原样重试只在本次授权及额度范围内进行。普通失败和质量偏差没有默认收费补制授权。每次重试重新核验正文、图片、引用、设置和预算。
- 直接暂停时不发起新提交；已受理任务仍可查状态和保存结果，不声称平台任务已取消。缺账号验证、费用授权或平台能力时，先完成不依赖该项的工作并报告准确断点。

## 成片与导出

- 分别记平台受理、可播放成片、内容审查、下载和本地顺序合片。明确免审时只核状态及可取得元数据，记 `not_reviewed`；要求审片时检查真实画面、切镜、人物、空间、动作、声源和受影响边界。未听音轨不宣称对白或 VO 通过，少量抽帧不宣称整片通过。
- 下载本次任务对应的原片，按集与单元顺序归档，核对文件可解码、大小、时长、尺寸、音轨及 SHA256。与旧文件同名不代表同一生成版本。保留失败和未下载清单。
- 完整制作时按序合片并核对时长、拼接点、音轨和集尾；有缺段就标“不完整”，不算完整交付。用户另行要求剪映、字幕、后期 VO、音乐或发布时按该任务再执行；不从完整视频授权推定这些额外操作。
- 局部补片在平台时间轴中的位置可能不同于本地最终接合顺序。记录正式交付采用的平台版本或本地接合版及其文件指纹；若采用本地接合版，核验保留前缀、补片、后缀、音轨和集尾后再交付，不能把平台一键导出直接称为已验收成片。
