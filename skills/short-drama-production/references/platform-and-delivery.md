# 网页执行、结果与本地交付

## 提交前

1. 进入用户指定的真实平台项目，核对登录、项目、集号、页面分镜序号及既有任务。工具或页面变化时读取当前状态与工具文档，不复用旧坐标、元素编号、模型价格或素材容量。
2. 从 `short-drama-studio` 生成的正式分镜提示词列出本单元全部必需人物、场景和道具及其时期，以及连续场的实际尾态与可用尾帧。将选定的实际尾帧归档为接续资产，记录源任务、取帧时间点、文件路径及指纹；提示词全文每次提及正式人物、场景、道具或尾帧资产，均写当前磁盘完整文件名主体（不包含扩展名），无称谓、简称、旧名或泛称代替。先核对项目规定的视频模式；没有规定时核对平台当前可用模式并选择能满足本次引用与接续要求的一种。`D:\短剧\八个哥哥` 的剧梦分镜视频生成及返修固定使用“全能参考”，不得转用“首尾帧”“视频编辑”“图片生成”等模式。查看实际图片，必要时按用户授权上传；在选定模式的真实选择器中形成本段全部必需正式资产及可用尾帧的引用节点。剧梦“一键引用”的“提示词中的名称”逐项填当前文件名主体，目标逐项选对应图片；不得用“参考图甲”等临时代号作为映射键。确认后读回正文，核对每项资产在总控、逐镜、技术首尾帧和硬约束中原本出现的各处均已形成对应真实节点，且原文对白、VO 和其他正文未变；不能只核素材声明行有节点或素材栏有缩略图。节点自动显示的扩展名按平台实际界面核对。若页面不支持同名处完整替换、节点目标不符或无法读回，暂停该次提交并报告具体缺口；项目锁定模式时不得为方便引用擅自切换。
3. 连续场先从前段成片末尾查明实际结束时的空间、人物、道具和光态，向前选仍代表最终状态的有效帧，不机械取文件最后一帧；跨集连续场也适用。分别评估该帧的空间可读性及脸、肤质、服装的生成参考质量。空间与下一首态冲突时先修订正式提示词；质量合格的尾帧在当前模式的真实节点绑定并读回。若尾帧空间可读但外貌失真，先选更早且仍代表最终状态的帧；仍不可用时，尾态只供人工空间核对，下一首态用正式人物及场景资产重建，在当前授权且不改变锁定原文边界时可合并相邻内容；改变锁定边界须按用户或项目确认规则处理，并记录不绑定原因、替代节点和空间风险。若强制绑定且无法兼容则暂停提交。文字说明、书面尾帧及缩略图不等于图像引用；成片后实看首尾衔接。
- 上传图片前检查当前平台接受的格式、尺寸、宽高比与文件元数据，并在页面确认受理。上传成功、映射键正确和素材缩略图出现仍须读回正文各处真实引用节点。

4. 按本项目解析模型、分辨率、画幅、时长模式；页面实际值、平台允许的最大时长和本次价格都要读回。切换分镜、打开历史或调整设置可能使时长等选项回到默认值，故在最终点击生成前重新读取当前分镜身份与所有参数，不以先前设置成功代替最终读回。页面正文除真实引用节点的展开形式外，须与正式提示词一致。发现超长、缺图、声音安排冲突或正文差异时，回到同一份正式提示词修订并重核；无法兼容时暂停提交并报告。
5. 记录正文与素材指纹、页面身份、参数、预算、尝试编号及实际价格，再点击生成一次。页面响应不明先查历史、队列或任务卡；不能为试探受理而再点一次。

## 受理、失败与暂停

- 受理后读回该次任务及真实引用，把提交后漏引用、在途、已生成和失败分别记。连续场下一单元需前段实际尾态时，等待该依赖；无依赖单元仍按本次授权与平台能力推进。
- 局部画面异常时先保留合格区间，记录原片版本、可剪接画面及时间点。当前项目与剧集的视频制作已获用户授权时，三次上限内无需逐次手动授权；仅将异常镜头与必要的邻近镜头写成一段短提示词，在原分镜位置以项目锁定的视频模式提交一次短时长局部新任务，避免重复生成多数合格镜头；若当前平台无法在原位置以该模式提交此类任务，先报告能力限制，不换模式或改用整段重生。首态依据紧邻保留段的实际结束状态，优先引用质量合格的**有效定位帧**：异常在中段用前方保留段末尾能说明人物站位的一帧，在开头且无本段保留前缀时用上一个连续分镜的有效尾帧；不能引用异常画面、书面预想尾帧或无关任务尾帧。补段首镜逐项核对角色空间站位、服装、道具和光态。补段完成后与原片合格区间拼接，核对原问题、前后拼接点和新尾态；未通过时记录问题，再决定是否使用剩余额度补制。
- 每个原分镜最多三次局部补制，首次补制和后续补制合计；先查历史次数再提交，每次核对实际价格与范围。已受理任务即使模型超时、参考图比例错误或产物不合格也计入，未受理的表单／审核拦截不计。三次后仍不合格就停止该分镜局部补制，保留原片合格部分，在最终问题清单写明位置、现象、三次尝试结果和剩余影响，由用户判断；不能通过另建版本或重投同一分镜绕开计数。只有用户明确更改上限时才覆盖。
- 剧本中的“脸色发白／turned pale”只用细微可信的生理变化及即时表演呈现：保留正式资产的肤色、妆容、肤质和场景光照，以笑容收住、呼吸停顿、眼神及唇部反应表现冲击，面部血色变化须轻微且与颈部、肩部一致。禁止整脸惨白或灰白面具、闪白、涂层、换脸、局部曝光突变、发光眼睛等效果。成片逐镜核对脸与颈部色调过渡及相邻镜头一致性；异常按局部规则记录镜号、时间点及受光状态，不把少量抽帧或提示词禁令当作已修复。
- 审核拦截须先确认原任务未受理或已终结。不得改写原文规避审核；原样重试须处于当前获准视频制作范围及该原分镜三次额度内。普通失败和质量偏差可在该范围与额度内继续补制，无需逐次手动授权；未获视频制作授权、用户暂停或跳过时不得提交。每次重试重新核验正文、图片、引用、设置和预算。
- 直接暂停时不发起新提交；已受理任务仍可查状态和保存结果，不声称平台任务已取消。缺账号验证、费用授权或平台能力时，先完成不依赖该项的工作并报告准确断点。

## 成片与导出

- 分别记平台受理、可播放成片、内容审查、下载和本地顺序合片。明确免审时只核状态及可取得元数据，记 `not_reviewed`；要求审片时检查真实画面、切镜、人物、空间、动作、声源和受影响边界。未听音轨不宣称对白或 VO 通过，少量抽帧不宣称整片通过。
- 人物身份或造型是返修目标时，先按剧本身份与正式角色资产明确应出现的人，再在实际成片的相关镜头核对脸、发型、服装和人物关系；素材节点绑定正确仍可能生成错误人物。只把经画面核对的区间记为已修复，其他合格区间沿用原验收记录。
- 审片沿事件推进查看开头、中段、尾段：确认地点、视角、高低关系、场面规模和必要人群确实可见；核对在场人数与每名角色身份、球衣或服装及道具，防止同一主角复制成队友。对白、否定词、引述和关键发音须听真实音轨，核对说话人与口型、画内画外声源；画外反应不能写成已看见的动作。
- 下载本次任务对应的原片，按集与单元顺序归档，核对文件可解码、大小、时长、尺寸、音轨及 SHA256。与旧文件同名不代表同一生成版本。保留失败和未下载清单。
- 完整制作时只按选定的完整分镜最终版顺序合片；局部补制先在单镜内接合并验收，再核对合片时间基、时长、画面及音轨接缝和集尾；有缺段就标“不完整”，不算完整交付。用户另行要求剪映、字幕、后期 VO、音乐或发布时按该任务再执行；不从完整视频授权推定这些额外操作。
- 局部补片在平台时间轴中的位置可能不同于本地最终接合顺序。记录正式交付采用的平台版本或本地接合版及其文件指纹；若采用本地接合版，核验保留前缀、补片、后缀、音轨和集尾后再交付，不能把平台一键导出直接称为已验收成片。
- 用户明确说暂不合片时，保存已验收的各镜视频和状态，停止在合片前；后续明确验收的可辨版本更新当前状态，历史待验收记录保留。
