# 状态和证据

每个项目保存一份主状态，具体文件位置遵从项目规则；过程核验材料如需留存放在项目指定的过程目录。状态只记录已核验事实，不用计划值填充网页或成片字段。

## 最小记录

| 对象 | 必记内容 |
|---|---|
| 来源 | 权威剧本路径、SHA256、语言、分集界与版本 |
| 授权 | 当前范围、资产生成范围、视频提交、导出、费用及暂停／跳过／补制指令 |
| 资产 | 人物／场景／道具的实际路径、类别、时期、尺寸、SHA256、验收状态 |
| 分镜 | `short-drama-studio` 当前规则指纹、正式分镜提示词指纹、源段落、时长、镜数、技术尾帧和待核实际尾态 |
| 网页 | 项目、集号、页面单元身份、真实引用键、实际参数、本次价格、尝试编号、受理与提交后引用证据 |
| 结果 | 可播放任务、实际音画审查范围、下载文件、合片文件、指纹和未完成项 |

状态词须分开使用：`drafted`（正式分镜提示词完成）、`prepared`（同一提示词与素材、平台参数核对）、`submitted`（确认受理）、`completed`（平台生成可用结果）、`reviewed`／`not_reviewed`（内容审查）、`downloaded`、`merged`。`unknown` 受理、在途、失败、跳过和阻塞另记，不提升为完成。每项保留观察时间和证据来源。

规则、剧本正文、资产图、正式分镜提示词或页面引用改变后，标出受影响的未提交单元并重查；旧尝试与费用不可覆盖。只改排版且正文和引用不变时可以复用有效检查。恢复时先读状态、实际文件和当前网页任务，再从最早缺证据的节点接续；不重传全量素材，不重复收费提交。

既有 1.1 项目不靠改技能名或配置版本自动迁移。先只读核对原项目的剧本、素材、任务尝试、费用与暂停状态；把已证实的事实接入新状态，新的正式分镜提示词按 `short-drama-studio` 规则重核。原有已受理与已完成结果保留其历史身份，不因新技能安装而重交或重制。
